# socket-pyserver

Простой HTTP-сервер на Python, реализованный с использованием стандартной библиотеки `socket`. Демонстрирует базовые принципы работы сетевых протоколов, обработки TCP-соединений и парсинга HTTP-запросов без использования сторонних фреймворков.

## Описание

Проект реализует низкоуровневый веб-сервер, который:
- Создает TCP-сокет и прослушивает входящие соединения на порту 5000.
- Принимает и декодирует сырые HTTP-запросы.
- Парсит метод и URL запроса.
- Возвращает валидные HTTP-ответы с заголовками и HTML-телом.
- Обрабатывает базовые HTTP-ошибки (404 Not Found, 405 Method Not Allowed).

## Архитектура

Проект состоит из одного файла `server.py` (или `main.py`), содержащего следующие ключевые функции:

- `parse_request()` — парсинг сырого HTTP-запроса на метод и URL.
- `gen_headers()` — генерация HTTP-заголовков и кода ответа в зависимости от метода и URL.
- `generate_content()` — формирование HTML-тела ответа.
- `gen_response()` — сборка полного HTTP-ответа (заголовки + тело).
- `run()` — инициализация сокета, привязка к порту и бесконечный цикл обработки клиентских соединений.

## Установка и запуск

Для работы проекта не требуются сторонние библиотеки, используется только стандартная библиотека Python.

```bash
# Клонирование репозитория
git clone https://github.com/Jenkins1607/socket-pyserver.git
cd socket-pyserver

# Запуск сервера
python server.py
